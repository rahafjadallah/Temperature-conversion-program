## 📌 About The Project

Temperature Conversion is a simple and interactive web application built using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius and Fahrenheit by entering a temperature value and selecting the desired conversion unit. The application calculates and displays the converted temperature with one decimal place.

## ✨ Features

- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Enter temperature values easily.
- Select the desired conversion unit using radio buttons.
- Display the converted result instantly after clicking the convert button.
- Format results to one decimal place.
- Display a message if no conversion unit is selected.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a temperature value.
5. Select Celsius or Fahrenheit.
6. Click the Convert button to see the result.
